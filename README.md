# MongoDB Library System

A full-stack library management API built with Next.js 14 and MongoDB. 

## Setup Instructions
1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Create a `.env.local` file in the root directory and add your MongoDB connection string: `MONGODB_URI=your_connection_string`.
4. Run `npm run dev` to start the development server.

## API Endpoints
* `GET /api/books` - Retrieve all books
* `POST /api/books` - Add a new book
* `GET /api/authors` - Retrieve all authors
